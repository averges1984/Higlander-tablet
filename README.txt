HIGHLANDER PASSENGER PORTAL

1) Open index.html in Safari on the iPad.
2) Edit the CONFIG section near the bottom of index.html:
   - driverName
   - phone
   - whatsapp
   - realtorHomesUrl
   - realtorRentalsUrl
   - wifiName
   - wifiPassword
3) Add the page to the iPad Home Screen:
   Safari > Share > Add to Home Screen.
4) For passenger use, consider Guided Access / Screen Time restrictions.

The buttons are functional:
- Entertainment/travel buttons open their websites.
- Moving to South Florida opens a real-estate page.
- Need a Ride Later opens a private transportation page.
- Text / WhatsApp / Call / Save Contact use the values in CONFIG.
